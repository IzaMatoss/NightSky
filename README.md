# 🌌 NightSky

NightSky é um aplicativo Android desenvolvido para registrar e visualizar observações astronômicas de forma simples e intuitiva. O projeto foi criado com foco em aprendizado de desenvolvimento mobile utilizando Kotlin e Android Studio.

O aplicativo permite criar registros de observações do céu noturno, visualizar listas de observações salvas e acessar detalhes de cada registro através de uma interface moderna inspirada no universo e na astronomia.

---

# ✨ Funcionalidades

- 📖 Lista de observações astronômicas
- ➕ Criação de novas observações
- 🔍 Visualização de detalhes das observações
- 🌙 Interface com tema espacial
- 📱 Compatível com dispositivos Android
- ⚡ Navegação simples e otimizada

---

# 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Android SDK
- RecyclerView
- Fragments
- Material Design
- ViewBinding

# 🚀 Como executar o projeto

## 1. Clonar o repositório

```bash
git clone https://github.com/IzaMatoss/NightSky.git
```

---

## 2. Abrir no Android Studio

Abra a pasta do projeto no Android Studio.

---

## 3. Sincronizar o Gradle

```text
File → Sync Project with Gradle Files
```

---

## 4. Executar o app

Conecte um dispositivo Android ou utilize um emulador e clique em:

```text
Run ▶
```
